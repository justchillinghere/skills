# Dignified Python

Opinionated Python coding standards for Codex agents.

This skill gives agents concrete rules for writing and reviewing Python in a deliberate, consistent
style. The core rules live in `core-standards.md`; version-specific typing guidance lives in
`versions/`; focused references and checklists live in `references/`.

## Usage

Install or expose this directory as a Codex skill named `dignified-python`. Agents should start from
`SKILL.md`, then load the referenced files according to the task.
